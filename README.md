# AI Algorithms Implementation

This repository contains Python implementations of three artificial intelligence algorithms:

1. A* Search Algorithm
2. Apriori Algorithm
3. Genetic Algorithm (Evolution-inspired algorithm)

These algorithms are commonly used in artificial intelligence, data mining, and optimization problems.

---

## Algorithms Included

### 1. A* Search Algorithm
A pathfinding algorithm used to find the shortest path between nodes in a graph.  
It combines the cost from the start node and a heuristic estimate to the goal.

Examples:
- Path from A to E
- Path from B to E

---

### 2. Apriori Algorithm
A data mining algorithm used for finding frequent itemsets and association rules in transaction datasets.

Examples:
- Minimum support = 0.4
- Minimum support = 0.6

---

### 3. Genetic Algorithm
An evolution-inspired algorithm based on natural selection. It uses selection, crossover, and mutation to find optimal solutions.

Examples:
- Optimization run 1
- Optimization run 2
